GREEN AFRICA WEBSITE - HOW TO REPLACE IMAGES

1. Open the "images" folder.
2. Copy your photo into it using EXACTLY one of these file names:

   logo.png                    200 x 200   (your logo)
   slide1.jpg to slide4.jpg    1600 x 700  (home page slider)
   mandate.jpg                 800 x 520   (Our mandate section)
   climate.jpg                 800 x 480   (Climate change section)
   news1.jpg to news6.jpg      600 x 300   (news cards)
   report1.jpg to report4.jpg  600 x 300   (annual report covers)
   partner1.png to partner8.png 300 x 140  (partner logos)

3. Refresh the page. Done. No code editing needed.

Until you add a file, a green placeholder from images/placeholders/ is shown.
Keep each photo under about 300 KB. Use .jpg for photos and .png for logos.
Edit the words (headlines, news, phone numbers) in index.html with any text editor.
To use a different file name or type, change the src="images/..." line next to the matching <!-- IMAGE --> comment.
